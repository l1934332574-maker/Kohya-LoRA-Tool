## 用户缺文件反馈

- 用户提供的说明中，异常发生在外部引擎 Python 执行 preprocess.py 动态读取 kohya_core/loss_masks.py 时。此异常说明该次执行使用的安装目录内缺少此文件，不是训练引擎缺少 pip 依赖。
- 当前发布的便携 ZIP 的 SHA256 为 3f4ebaaebf2125e31c52e14826e0070c83527424620bac39d2c4fe1e8c8be1d7，内含 loss_masks.py 和 loss_mask_worker.py。Inno Setup 的最终构建日志也明确记录两者入包。不能据此认定所有 v0.19.18 发布包都漏打；仍缺受影响用户安装目录清单、实际运行路径和安装日志。
- 用户的精简模块中 sync_activation 是空操作，缺文件兜底的 import_mask 也直接返回。27 张图打标完成不能证明遮罩成功导入或同步，不适合替换正式实现。
- 已从已发布便携包提取两个原始正式组件组成独立修复 ZIP，附使用说明和哈希；不是本次修改后的源码。仅用于相同版本的缺文件恢复，用户机恢复情况尚待反馈。

## 本地源码已改

- preprocess.py 缺少遮罩模块时输出确切路径、覆盖安装位置与恢复提示；加载失败保留真实原因。验证正式模块的必要接口，拒绝空操作兼容替代。不会静默跳过遮罩。
- 发布检查的文件存在及源码一致性清单加入 loss_masks.py、loss_mask_worker.py。
- 本地遮罩检查使用 EXIF 转正后的图片尺寸；原始遮罩导入区分原始像素尺寸与已经转正的尺寸，避免对已转正的长方形遮罩重复旋转。正方形、镜像或 180 度无法只靠尺寸分辨时按已转正遮罩约定处理。
- 仅做了源码语法和差异格式检查；本次未执行训练、GPU 验证、新安装包构建或用户机复验。

## 官方 v8.9.7

直接读取 GitHub 官方 API 的 latest、release tag、v8.9.6...v8.9.7 compare：

- 最新版本：v8.9.7；发布时间 2026-10-25 12:43:57 UTC，即北京时间 20:43:57。
- 提交：fe32a56ce504a15c8448c9ba9043390762de459e。
- 新增 mask_prior 参数，默认 0；界面提供关闭、0.5、1、2。每步额外运行一次关闭 LoRA 的底模前向，约束遮罩外区域接近底模预测；与 mask_floor 降低遮罩外真实图片监督强度不同。官方说明新增耗时从几个百分点到约 50%，取决于模型。
