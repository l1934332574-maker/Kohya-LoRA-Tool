# 本地图片自然语言描述：实施说明

日期：2026-10-04
状态：纳入 v0.19.0（2026-10-05）发布；未进行真实视觉服务或 GPU 联调。

## 入口与范围

运行本工作区的 kohya_gui.py，进入新版训练页，在“准备图片数据／数据与训练方式”中使用“图片标签与描述”。

提供三种方式：

- 关键词标签（WD14）：保留已有 WD14 流程和模型选择。
- 自然语言描述：中文／英文，简短／详细；支持视觉服务预览与批量生成。
- 使用已有文本：不调用模型生成，使用同名 .txt。自然语言文本请选择自然语言模式，避免标签式触发词处理。

新版第一引擎、Qwen/Z-Image 和其他图片训练页面复用同一个控件。视频描述不在本次范围；混合媒体目录的描述生成仅处理图片，视频和音频仍需单独准备字幕。旧 Tk 界面保留项目的描述选项并可执行预处理与训练，但没有新增视觉服务设置面板；配置和生成请使用新版界面。

## 服务接入

第一版不下载或捆绑看图模型，不在训练进程中加载视觉模型。

1. 兼容视觉接口：填写基础地址，例如 http://127.0.0.1:1234/v1，程序调用 chat/completions，使用 image_url 图片输入。在线服务需要 HTTPS。
2. Ollama 本地服务：填写本机根地址，例如 http://127.0.0.1:11434，调用原生 api/chat。

模型名必须是服务实际提供、支持看图的模型；不是 Anima、Qwen-Image 等训练底模。连接形式兼容不代表每一个服务及模型都已验证。

API 密钥单独使用 Windows 当前用户的 DPAPI 加密保存于数据目录 settings/caption_service.json；不会保存到项目 JSON。界面只显示是否已有密钥，不读取明文。更换服务地址且不填写新密钥时，清除旧密钥，避免发送到新地址。项目保存描述方式、语言和长度。

对非本机服务，每次开始描述任务需要勾选允许发送图片；预览也会调用服务，可能收费。图片请求使用缩小后的 JPEG 副本，原图不改动。

## 使用流程

1. 选择图集，选择自然语言描述、语言和长度。
2. 展开服务设置，填写地址、视觉模型和密钥（如需要），保存。
3. 先预览最多三张：展示图片和描述，预览不写同名文本。
4. 确认方向正确后批量补齐；默认不覆盖已有非空文本。
5. 如果原来已有 WD14 标签，希望换成完整描述，需要主动选择“重新生成已有文本，并备份原文件”。
6. 保存项目设置，再按原流程预处理／一键训练。自然语言模式训练只读取已有文本，不自动调用描述服务。

同一次应用运行内，如果图片、模型、服务、语言和长度未变，批量生成复用成功的预览结果，减少重复调用。预览不保证所有描述准确，仍需查看和修改原图旁的 .txt。

## 文本保护与训练流转

- 生成失败、空响应、已标明截断或拒绝的响应不写兜底文本。
- 批量任务显示进度，支持停止，以及只重试失败图片。
- 停止后保留已完成的文本；再次“只补缺失”可以继续。已发出的 HTTP 请求可能仍在服务端执行，但取消后的迟到响应不会继续写文件。
- 覆盖已有文本前备份到原图目录 .caption_backups 下的任务文件夹；输出训练目录同步修改也保留旧文本备份。
- 写入采用临时文件替换；生成期间图片或同名文本被修改时，不覆盖新内容，报告该图片失败。
- 自然语言预处理跳过 WD14、人物标签过滤、概念关键词清洗、标签强绑定和统一兜底。触发词独立放在描述首行，描述正文不拆成标签。
- 即使训练图片已经存在，重新预处理仍同步原图旁的文本，不再因图片跳过而忽略新描述。
- 自然语言文本不齐全时阻止训练，并提示先补齐，不能用统一占位句子假装生成成功。
- 训练启动阶段的强绑定再次处理也已对自然语言模式跳过；全局提示词注入用换行连接正文。
- 已有文本保护路径同样不再在“最终兜底”阶段偷偷补写占位句子。

## 资源管理

Ollama 默认在任务结束后请求卸载本次模型，失败时提示人工检查显存。通用接口没有统一卸载协议，界面明确提示用户在本地服务中释放模型后再训练。取消时服务端推理是否立即停止，取决于服务，不能保证。

## 报告与限制

每次生成任务在数据目录 logs 下保存 caption_<任务ID>.json，记录逐图状态、成功描述、错误、语言和模型等，不包含 API 密钥或图片数据。应用内保留最近少量结果用于展示和失败重试。

目前的验证范围：Python 语法检查、Vue 类型检查与前端构建、静态检查文本流转。未调用真实视觉 API、未运行实际批量图集、未进行 GPU 实训，未验证某一看图模型生成中文描述的质量。未新增或执行自动测试。

不承诺中文描述比英文更好，或自然语言比关键词更好；是否适合某个底模需要对比训练效果。

## 关键本地文件

- kohya_core/captioning.py：服务、密钥保存、请求、生成、备份与取消。
- gui/modern_host.py：服务设置与描述任务接口、任务互斥和结果。
- modern_ui/src/components/CaptionControls.vue：共用配置和预览操作面板。
- kohya_core/project_config.py：项目描述选项与实际训练参数。
- preprocess.py：同名文本同步、自然语言保护和缺失拦截。
- Kohya一键工具.py：预处理接线与各训练入口的自然语言保护。
