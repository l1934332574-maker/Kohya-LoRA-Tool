# 全局训练助手与内置 Agent：本地实施说明

> 更新提示（2026-10-05）：下文记录的是上一批本地实现，部分行为已被新方案替代，例如执行期间锁住页面、每次卸载文字模型和独立目标式交互。当前改进说明见同目录《训练Agent_交互与电脑工具改进_20261005.md》，以当前代码与新说明为准。

本批实现已纳入 v0.19.0（2026-10-05）发布。本说明记录早期设计，当前行为以《训练Agent_交互与电脑工具改进_20261005.md》为准。

## 入口与两种工作方式

重新运行本工作区 kohya_gui.py，在新版界面左侧导航的软件名称下方点击“训练助手”。旧 Tk 界面没有这个新面板。

- 只分析／给修改建议：每次独立请求，可勾选附加当前项目最近任务日志；差异展示后点击应用，支持最近方案撤销。
- Agent 自动执行：输入目标后连续调用真实工具；信息不足时提问，用户回答后继续。打开项目后绑定该项目，首页开始时可以先询问模式再创建项目。

切换到自动执行后，点击“交给 Agent 自动执行”即允许本次项目的常规配置保存、准备、开始／续训及任务处理。额外安装、模型下载和在线图片发送有单独范围；未允许而确有需要时，由软件提出专门的授权问题。普通模型对话不能直接改变这些权限。

## 让接入的模型熟悉工具

每次开始先读取真实环境，并把它与工具目录交给模型：

- 应用版本、系统、显卡型号／显存、内存、Python 版本／来源。
- 基础 Git／Python 与四类引擎的安装标记状态；标记不代表所有依赖可用，详细状态由训练预检确定。
- 项目模式、底模类型、已选图集／底模状态、描述方式、触发词、已保存参数和默认合成参数。
- 模式与引擎对应、最少样本数、适用参数、量化枚举、数值范围、特殊限制。
- 工具名称、用途、参数格式和行为约束；可随时刷新环境、读取模式说明或真实预检。

说明来自当前代码的能力定义，而不是要求用户手动写一大段软件介绍。原有参数提示仍可能有概括或过时文字，模型必须以真实预检和执行结果为准。读取环境不保证模型正确理解所有能力，更不保证得到最优参数。

## 当前注册的操作

- 熟悉环境，查看项目与模板，绑定用户选择的已有项目或创建项目。
- 通过原生选择器让用户选择图集或第一引擎底模，不猜测任意文件路径。
- 读取项目、模式说明、检查图集；修改适用参数、训练类型、触发词、AMD／文本编码器开关、图片描述设置。
- 撤销本次 Agent 最近一项项目配置修改，后续项目变化时拒绝覆盖。
- 图片描述、预处理、训练预检、开始／续训，并等待任务结束。
- 模型文件清单、内置下载入口、Qwen/Z-Image 受管模型选择。
- 调用既有前置环境／当前引擎安装修复流程。
- 查看当前项目训练记录及当前任务采样文件清单。

Qwen/Z-Image 模型设置沿用软件原来的同模式共享设置；修改会影响同模式其他项目的后续训练。选择前后写入本地备份，项目配置撤销工具不撤销这项共享设置。其他模型组件仍按各自内置模型管理流程处理。

没有开放任意命令、任意源码修改、删除项目／数据、自动生成训练图、视觉采样评价。Agent 只可使用已注册工具，不等于软件所有内部 Python 函数都对模型开放。

## 执行闭环与提问

目标 → 读取环境／项目 → 模型输出一个结构化动作 → 校验 → 软件调用实际工具 → 返回结果 → 模型决定下一步。

缺少信息时，显示问题、可选答案与输入框。回答会连同原目标和近期工具结果继续传入模型。取消文件选择时返回明确结果，不能猜测用户想用哪个路径。较早上下文会裁剪，并补充当前项目状态。

常规已授权步骤不重复要求确认。下载、安装和在线图片发送的专门授权按钮只影响本次范围。拒绝时不会绕过，Agent 可说明如何手动处理。

长任务由原有任务系统执行，Agent 等待实际状态，不每隔几步再次调用模型。出错后把任务尾部最多 100 行日志及有效参数等返回模型，再决定配置修复、既有环境修复或向用户提问。日志可能不完整，不能保证自动诊断所有故障。

## 预处理检查和训练

train 工具调用完整一键训练，已经包含预处理，不应先无目的地重复处理。预检失败不算训练已启动。

“标签完整且无缺失警告时自动继续”默认开启。这里检查文件／文本完整性，不能判断图片与文字是否匹配。缺失、空文本、有打标缺失警告、媒体字幕需要人工核对，或用户关闭自动继续时，尝试打开标签编辑器并等待用户明确选择继续或取消。

原有训练／环境流程本身可能自动下载组件或修复依赖，Agent 沿用这些实际行为；范围控制首先限制 Agent 主动调用的工具，不是对所有第三方引擎内部网络行为的拦截。

本次最多 32 次模型决策、三次训练尝试。同一操作反复失败会限制重试。模型选择结束不意味着训练成功；实际尝试训练但没有成功完成时，界面标记失败并保留任务结果。

## 记录、停止与恢复

- 自动执行期间锁住普通训练页；关键保存与任务接口也检查 Agent 所有权，避免交叉操作。
- 项目在执行期间被外部修改时，配置保存拒绝覆盖，需要停止后重新交代目标。
- 数据目录 agent_runs/run_<ID>.json 保存目标、问题／回答、脱敏环境和执行记录；change_<ID>_<序号>.json 保存涉及的项目原值与修改值；model_<ID>_<序号>.json 保存受管模型选择备份。备份可能包含用户选择的本地路径，留在本机，不送给模型。
- 记录 pending 是修改前备份，applied 表示配置已保存。磁盘异常时应核对项目当前值，不根据聊天文本判断。
- 关闭侧栏不停止 Agent；主界面仍跟踪所有权，重新打开继续查看。
- “停止 Agent，保留任务”阻止后续动作，已有软件任务继续；“停止 Agent 和任务”还请求停止本次任务。停止是请求，原生选择器需要用户关闭，服务端推理可能暂时继续。
- 软件重启只恢复最近执行记录供参考，标记中断；不自动恢复操作、不自动重开训练。核对实际进程后重新交代目标。

## 模型连接与信息发送

文字连接与图片描述连接分开，支持本机 Ollama 与兼容文字接口。自行提供模型，不捆绑大语言模型。

密钥使用 Windows 当前用户 DPAPI 加密，独立保存于 settings/assistant_service.json，不进入项目、模型上下文或 Agent 记录。

自动模式的文字请求包括目标／回答、系统与显卡、目录、当前项目、工具结果和排错所需日志。通用结果隐藏直接路径字段和密钥字段，文字做基础脱敏；用户输入和日志仍可能含敏感内容，脱敏不保证全部去除。图片由独立视觉服务处理，发送到本机之外另需允许。

Ollama Agent 每次模型决策请求结束后要求卸载模型；取消不保证服务端立刻停止。兼容接口没有统一卸载协议，本地使用需在模型服务中释放资源后训练；本版尚不能确认通用服务已释放显存。Agent 开始时若已有软件任务运行，会要求先结束或停止；之后由 Agent 开启的任务可持续等待和诊断。

## 当前验证范围

完成 Python 语法检查、接口引用静态核对、Vue 类型检查、本地前端构建及差异格式检查。

没有连接真实文字／视觉服务，没有实际调用 Agent 工具链，没有执行自动测试、下载、环境安装、参数应用／撤销或 GPU 训练。结构化输出兼容、连续提问、任务交接、自动修复效果与各模式实际训练仍需联调，不能按成熟的无人值守训练器宣传。
