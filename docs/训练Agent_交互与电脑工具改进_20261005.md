# 训练 Agent 交互与电脑工具改进

日期：2026-10-05
状态：纳入 v0.19.0（2026-10-05）发布；本文保留实现与检查范围，未做真实服务联调。

## 已确认的使用流程

用户只需描述目标，例如“我要训练 LoRA”。助手先询问要学习人物、画风还是一种概念，再确定要配合哪个底模使用。每次只提出一个关键问题；给出可点击选项，也允许自由输入。显卡、软件版本、安装状态和已经提供的文件由工具检查，不要求用户重复填写。

缺少文件时，用户可以粘贴路径或者点击选择文件／文件夹。先检查路径与文件，再继续准备。信息足够后展示训练方案，授权了“准备好就开始”的任务直接执行；其他任务在开始前确认一次。

## 聊天界面

- 默认进入持续对话，参数建议方式作为辅助入口。
- 文字逐步显示；仅展示模型回复中的用户说明，不展示 JSON、工具参数或推理过程。
- 选项点击即提交，带问题标识，旧问题的选项不能授权新操作。
- 输入框在任务执行期间仍可输入；补充要求排入当前任务，在下一安全位置调整。
- 用户阅读历史时不强制滚到底部；主动发送后跟随最新消息。
- 主界面保持可查看。需要手动修改时点击“我来操作”，助手先交还控制；继续前重读实际配置。
- 详细执行记录默认收起，保留用于排错。

## 项目记忆与控制

- 按项目保存对话、阶段、工具结果和必要上下文；起始页对话创建项目后归入该项目。
- 项目 A 的聊天与执行不能混入项目 B。一个执行控制器同一时间只操作一个项目。
- 关闭侧栏不停止任务。重启只恢复记录，不自动启动训练。
- 继续前检查现有任务和配置；不能凭旧记录判断训练进程仍在运行。
- 暂停助手、停止训练、手动接管分别处理。暂停助手不暗中取消已经运行的软件任务。
- 相同失败连续两次停止自动重复尝试，请用户选择下一步。保留最多三次训练启动与每轮最多 60 次模型决策的上限。记录保留有长度限制，超长对话会只向模型提供当前目标和近期证据。

## 训练方案与结果

方案默认显示目标、底模、样本数、分辨率、训练步数／轮数、描述方式、采样预览、输出目录、警告。详细参数和本次修改放在展开区。数据来自真实配置及预检，不把模型猜测当作已确认值；无法估算的显存与耗时不做承诺。

结果区分成功、失败、用户停止。只有实际生成采样才展示图片入口。训练成功只说明生成了产物，不凭 loss 判断质量。提供适用的输出目录、采样、日志、继续训练入口。

## 模型与组件

- 现有引擎、环境安装及受管模型下载继续调用软件原有流程。
- 扩展查找 Hugging Face／ModelScope 公开模型仓库、查看实际文件目录、下载用户选择的模型文件。
- 默认下载到当前模式模型目录；自定义目录必须是用户明确提供的目录。
- 下载前说明来源、具体文件和目录。本轮勾选允许安装／下载后按该范围执行；未勾选时就具体操作提问，单次外部文件确认不扩大到后续全部文件。支持进度、取消、部分文件续传、文件完整性检查。
- 取消检查在元数据请求与文件读取之间进行；单次卡住的元数据请求可能等待 30 秒、文件读取可能等待 60 秒。
- 下载完成不等于模型与当前引擎兼容。不能自动把 VAE 或 LoRA 当成训练底模。
- 受限、付费、需要账号授权的模型不绕过访问控制；公共下载器不保存第三方账号。

## 电脑操作

电脑工具与训练工具统一进入可调用目录，但操作权限分开处理：

1. 软件目录、数据目录和用户明确选择的目录可以列目录、读取常见文本；凭据文件不进入模型上下文。
2. 可以请求在默认浏览器打开网页，不等于已经提供浏览器页面阅读和鼠标点击能力。
3. PowerShell 命令每条展示用途和完整命令，由用户明确点击确认后使用一次性授权执行。普通聊天不能替代命令授权。
4. 运行权限与训练器当前进程一致，不自动提升为管理员。命令有执行超时、输出长度限制、取消与基本脱敏；取消不代表已经发生的系统修改被撤销。
5. 修改源码、覆盖成果、删除文件仍属于需要具体确认的电脑操作。当前不提供无限制后台运行或静默全盘修改。

## 本地模型性能

Ollama 在连续聊天阶段保持模型驻留，避免每步重新加载。GPU 训练前请求卸载文字模型；通用兼容接口缺少统一卸载方法，需要明确提醒用户释放显存。真实逐步显示依赖连接的模型服务支持流式回复，不使用打字动画伪造流式生成。

## 检查与限制

本批检查仅包含 Python 语法、接口引用、前端类型与构建、修改差异检查。未实际调用用户模型服务、下载大模型、执行电脑命令或运行 GPU 训练；因此不能据静态检查宣称完整真实环境闭环已验证。后续应使用用户实际服务走一次“我要训练 LoRA”的完整流程收集反馈。


## 本轮用户反馈修正（2026-10-05，本地）

### 回复报错与重复消息

原传输层将流事件的协议字节一起累计到 512 KiB 上限，正常内容并不需要达到这一长度也可能失败。现在将单行事件限制与整轮协议限制分开：单行 512 KiB、整轮 8 MiB，正文仍限制 30,000 字符；没有正文的推理增量不进入 UI 消息队列。长度截断、服务过滤、超时分别说明，不再一律要求用户缩短目标。空白助手消息不保存，旧记录中的空白气泡在界面隐藏。真实服务响应仍需联调，不能仅凭这一改动保证所有提供商兼容。

### 软件任务与聊天分别反馈

- 助手启动训练后，主界面自动接入已有训练任务，打开原有训练窗口；读取实际日志、步数、loss 和采样，不重复调用启动接口。
- 安装、下载和独立预处理同样接入任务窗口，支持最小化后继续与助手对话。
- 侧栏保留当前任务摘要和进度窗口入口，任务进行时即可查看日志。
- 窗口停止时同时停止对应的助手，避免助手把主动停止误当成失败并再启动；人工标签确认通过当前问题标识交回助手。
- 查看输出目录、导出诊断以及当前训练等待检查时的标签编辑器不会被助手控制权拦截；修改其他配置仍按接管流程处理。
- 主界面同步项目配置时不重新打开项目，避免反复刷“已打开训练页”日志与重建界面。
- 切换任务时丢弃迟到的旧状态；轮询限制并发，界面只保留近期日志，完整记录仍使用现有导出入口。

### 界面整理

默认显示对话、一个当前问题和真实任务摘要。工具调用合并为一个收起的记录区，执行方案在需要确认时展开；其他时候可手动查看。权限、文字连接、参数建议入口归入设置。阶段名称使用中文，清理重复错误与重复选项。助手面板使用不透明背景保证可读性，并响应明暗主题及减少动画设置。

### 底模文件预检

新版第一引擎的 safetensors 底模在训练预检时检查头部偏移与实际文件长度，头部读取最多 64 MiB，不读取完整权重。张量偏移不连续、重叠、尾部多出或缺少数据时，直接报告文件问题。该检查只检查布局，不替代模型架构兼容检查、哈希验证或真实加载。

本机 `anima-base-v1.0.safetensors` 的只读检查发现实际载荷比头部最后一个张量声明多 262,144 字节，与截图中的 `file not fully covered` 一致。没有对模型文件作截断、覆盖、移动或下载。此问题与 2.9B 的 40 层支持是不同原因。


本轮最终静态检查：15 个 Python／打包配置文件语法通过；59 项前端接口调用均能对应后端方法；Vue 类型检查与生产构建通过，构建首页引用的两项资源实际存在；按仓库 Windows 换行方式检查差异通过。版本保持 `0.18.16`，没有提交、推送或发布。


## 助手界面重新设计（2026-10-05，仅本地）

用户截图显示连接设置中复选框与文字错位、横向滚动、设置和聊天内容相互挤压。源代码中 `.service-settings input { width:100% }` 同时作用于复选框，是一个明确的布局原因。

本轮将设置界面独立为 `AssistantPreferences.vue`，划分连接服务与执行权限两个页签，使用单独的纵向滚动和固定底部操作区。复选框固定 16px，说明文字使用 `minmax(0,1fr)` 布局；连接输入框与复选框不再共用宽度规则。授权与现有执行流程保留。

聊天默认展示对话、可点击问题和紧凑的任务摘要。工具调用、环境目录与日志放进执行记录页签。设置可以从头部入口或底部模型名称打开，窗口可以展开到更宽的聊天视图。助手控制放在状态栏，暂停／继续可直接点击，接管与停止在更多菜单中。

回复使用安全的 Vue 文本节点显示基础标题、段落、列表、加粗、行内代码和代码块；不执行模型返回的 HTML、不自动执行或打开链接，不宣称支持完整 Markdown。输入框固定在底部，发送按钮与收起按钮分离；进入设置、查看记录和返回对话时保留草稿与阅读位置。明暗主题、窄窗口和减少动画偏好均有对应样式。

检查仅限接口对齐、Vue 类型检查、生产构建及资源引用、修改差异。没有运行 AI 服务或 GPU 训练，没有对原生窗口做自动化操作或实机布局测试；仍需要用户重启工具查看实际显示效果。不发版、不推送、不修改版本号。


### 助手入口位置调整（2026-10-05，仅本地）

将右下角悬浮入口移到左侧导航顶部的软件名称下方。首页及各模式共享同一个入口，显示打开／收起状态及执行指示。侧栏顶部独立占位，引擎列表与引导内容使用单独滚动区域，避免入口覆盖日志、滚动条、任务小窗口或其他按钮。展开的聊天面板继续使用现有右侧窗口，关闭入口不停止任务。检查为类型与构建、入口引用及差异检查，未进行实机交互测试。
