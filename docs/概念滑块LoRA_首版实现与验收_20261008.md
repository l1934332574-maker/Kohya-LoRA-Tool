# 概念滑块 LoRA：首版实现与验收记录

日期：2026-10-08。状态：本地实现，实验性入口；未发版，未完成 GPU 实训与目标推理工具验收。

## 使用流程

新建项目 → 选择 SDXL 或标准 28 层 Anima → 训练目的选择「概念滑块」。

1. 选择底模；页面提供获取模型、准备环境与 Anima 组件的入口。
2. 给滑块命名，选择双向变化 / 减少一种效果 / 增强一种效果。
3. 默认用文字：填写共有画面与方向描述，不需要图片、标签或触发词。自有效果可改用对照图片。
4. 先做 128 步试训，结束后查看同条件的五档权重对照。确认方向后可选 768 步正式训练或自定义步数。
5. 在不同场景、种子及检查点上核对效果，选择准备使用的检查点，保存人工核对结果，并通过保存窗口导出这一份 LoRA。

0 是停用 LoRA 的底模表现；双向正负值分别学习两端，单向正值表示更多地实现所选目的。零不是参考图的平均状态。

## 已实现范围

| 部分 | 本地实现 |
| --- | --- |
| 独立页面 | 目标、训练依据、训练量、权重对照四个区域；高级参数默认折叠；无固定概念模板 |
| 训练目标 | 复用固定 Fizgig v7.0.1 的真实文字 / 图片对正负倍率目标；冻结底模及文本编码器，只更新 LoRA |
| 版本与隔离 | 固定上游提交 1c8ec88edc1a4f99f73585aeae00fec740b12ea6；工具后端版本 1；扩展仅在训练子进程内应用 |
| 材料 | 自动同名配对，可手动修改并预览；同步中心裁剪，不覆盖源图，不做普通逐图打标或单边模糊过滤 |
| 留出验证 | 至少 6 组独立图片对时留出约 20% 整组；字节相同或共用端点的材料保持同一集合；重编码 / 近似重复仍需用户核对 |
| 训练设置 | 起点为 rank 8 / alpha 8 / 学习率 5e-5 / 512px / 自动底模精度 / 批量 1；可调整，不能称为最优参数 |
| 任务 | 共用可见训练窗口、实时日志、进度、停止、训练记录及恢复设置；普通预处理入口明确阻止滑块误入 |
| 对照采样 | 双向 -1 / -0.5 / 0 / 0.5 / 1；单向 0 / 0.25 / 0.5 / 0.75 / 1；每行只改变倍率 |
| 采样频率 | 试训仅结束时对照，中间仍保留检查点；正式 / 自定义定期对照并包含最后一轮。采样需要额外时间 |
| 泛化观察 | 验证描述不参加训练；留空增加两种构图。试训一组种子，正式 / 自定义两组种子；最多四条自选验证描述 |
| 数值参考 | 最多两对留出材料，以相同噪声比较停用 / 使用 LoRA 的误差。数值不能替代目标方向和画面保持的人工检查 |
| 导出与检查 | 原生 safetensors LoRA，记录方向与来源元数据；检查非有限权重、可识别权重和实际更新；每次训练使用独立目录；选择检查点后可直接导出，不必手动寻找文件 |
| 设置 | 配置保存与导入导出、Agent 的 configure_slider、训练队列接入；配置分享不带图片目录、配对清单或 API 设置 |
| 效果判断 | 切换检查点重新核对方向、主体 / 画风保持、换场景和种子后的效果；生成文件仅标为「产物已生成，待查看效果」 |

按完整轮次向上取整，因此图片对数量可能让实际步数稍高于目标。正式档增加步数，文字模式还增加练习画面数量；不是自动提高质量或防止过拟合。

## 首版限制

- 仅 SDXL 与标准 28 层 Anima 的 Fizgig v7.0.1 实验性入口；40 层 / 2.9B 尚未接入滑块。
- AMD 普通训练可用不等于滑块已验收，AMD 滑块仍需单独实测。
- 每次从头训练；保留训练状态与检查点，但首版不开放续训。
- 文字模式依赖底模对概念的理解。不能承诺从文字学会底模不认识的新风格。
- 一对图片可试训，不能证明泛化；增大步数不能替代构图和样本多样性。
- 未实现自动生成对照图、训练中自动挑选最佳产物、其他模型的滑块适配。

## 2026-10-08：结束后采样被误停

第二轮 128 步试训增加两条验证描述，需生成三组、共十五张对照画面。日志显示训练于 23:32:08 跑满步数，23:32:19 开始采样，23:34:57 被通用 150 秒收尾看门狗误判并停止。停止时还没有对照 PNG 和最终检查点，保留了截至第 24 轮的检查点与训练状态。

本地修正：

- 子进程明确报告训练、采样、保存阶段；采样期间不按训练收尾超时自动停止，保存阶段仍保留保护。
- 按固定描述与种子逐组渲染、保存对照，每张画面报告实际生成进度；已保存组即时写入结果记录。
- 任务窗口在采样 / 保存时显示当前阶段，不将 128/128 的训练计数作为整项任务完成。
- 强制停止时由主进程补写取消 / 失败状态，避免结果记录永久显示 running。

修正后用户反馈流程正常，纳入 v0.19.2 发布批次；不同模型与硬件上的效果仍需继续核对。没有改动训练目标、学习率或正负倍率，也没有修改已安装的上游源码。
